# AURA-Updates

Public update metadata for the AURA mix-analysis plug-in by ACAS Tools.

AURA's **Check Updates** button (Settings panel) fetches
[`update-manifest.json`](update-manifest.json) from this repository's `main`
branch and compares `latestVersion` with the installed version. Nothing is
fetched until the user clicks, and no user data is sent.

Release notes live in [CHANGELOG.md](CHANGELOG.md). Plug-in source is in the
private [AURA](https://github.com/Autonomous-Capital-Allocation-System/AURA)
repository.
